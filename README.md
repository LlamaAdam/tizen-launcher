# tizen-launcher

A clean, Apple-TV-style home screen for Samsung Tizen TVs, run through
[TizenBrew](https://github.com/reisxd/TizenBrew). No root; nothing uninstalled
that can't be restored.

Add it in TizenBrew's module manager as: `gh/LlamaAdam/tizen-launcher`

Early work in progress. This revision is a launch spike that verifies a
TizenBrew module can open the TV's native apps.
